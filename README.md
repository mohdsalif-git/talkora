🌍 Talkora
No Accounts. No Borders. Just Conversations.
Talkorais a free, worldwide anonymous stranger communication platform designed to bring people together through real-time text messaging and audio conversations.

Users can instantly connect with strangers from anywhere in the world without creating an account, sharing personal details, or selecting a country.

✨ Key Features
🌍 Worldwide random stranger matching
👥 Opposite-gender matching (Male ↔ Female)
💬 Real-time text messaging
🎙️ Audio-only calling
🔄 Instantly connect with another stranger
🟢 Live visitor counter
📊 Total website visit counter
🔐 No registration or login required
🗑️ No persistent chat history or audio recordings
📱 Responsive mobile and desktop interface
🆓 Free access
🛠️ Technology Stack
Frontend: React, TypeScript, Tailwind CSS
Backend: Node.js, Express.js
Real-time communication: Socket.IO
Audio communication: WebRTC
Database: MongoDB Atlas
🔒 Privacy First
Voxora is designed around temporary conversations. Messages, audio recordings, user profiles, and individual conversation histories are not stored in the application database. Only anonymous aggregate website statistics are retained.

🎯 Our Mission
To make worldwide communication simple, accessible, and free — one stranger, one conversation, and one connection at a time.
